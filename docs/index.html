unsat-with-receipts — a SAT solver that shows its work

A CDCL SAT solver in Rust that emits DRAT proofs. Every UNSAT verdict comes with a receipt that an independent checker (drat-trim) verifies. Repo: az9713/unsat-with-receipts.

The claim, and the evidence for it

A SAT answer is easy to trust: the model is checkable in linear time. An UNSAT answer is a claim that no assignment works. This solver backs that claim with a DRAT proof, checked by drat-trim — a tool this project did not write. Two independent gates back every milestone:

Demo 1 — circuit equivalence with a receipt

Two 16-bit adders — a ripple-carry adder (majority-gate carries) and a carry-lookahead adder (generate/propagate) — Tseitin-encoded into one miter: outputs XORed, "some output differs" asserted.

$ miter --bits 16 --proof miter16.drat --dimacs miter16.cnf
c miter: 16-bit ripple-carry vs lookahead, 178 vars, 565 clauses
s UNSATISFIABLE
c circuits are EQUIVALENT (miter has no distinguishing input)

$ drat-trim miter16.cnf miter16.drat
s VERIFIED

The negative control: --buggy drops one propagate term in the lookahead carry chain. The miter goes SAT and the model decodes to a concrete counterexample:

$ miter --bits 8 --buggy
s SATISFIABLE
c circuits DIFFER; counterexample: a=8 b=10 cin=1
c ripple-carry says 19, lookahead says 51 (true sum 19)

Demo 2 — Sudoku uniqueness, proven

The encoder solves a 9×9 puzzle, then adds a blocking clause that forbids the found solution and re-solves with proof logging on. UNSAT means the solution is unique — and the DRAT proof is the receipt for that claim.

$ sudoku --proof sudoku.drat --dimacs sudoku.cnf
c solved: (grid)
s UNSATISFIABLE (blocked) — solution is UNIQUE

$ drat-trim sudoku.cnf sudoku.drat
s VERIFIED

Known deviations

Two, both documented in the README and the M4 commit message: the 60 s tier uses SATLIB DIMACS sets rather than SAT-Competition instances, and the dubois series is excluded because the SATLIB files are malformed.
